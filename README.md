# Past ESP32 / Arduino home builds

Personal ESP32 and Arduino sketches from a small home stack: wireless door sensors, Wi‑Fi blinds, and lamp automation.

Each folder is one project from the [portfolio writeup](https://nmahadevan12.github.io/projects/esp32-home-builds/).

| Folder | What it is |
| --- | --- |
| [`espnow-door-sensor`](./espnow-door-sensor) | Door system — `node/` · `hub/` · `logger/` · `discord-hub/` |
| [`home-automation`](./home-automation) | Hub + Wi‑Fi blinds + lamps (`hub/` · `blinds/` · `lamps/`) |
| [`photo-blinds`](./photo-blinds) | Photoresistor + motor blinds with auto / manual modes |

## Setup notes

Wi‑Fi SSIDs, passwords, phone numbers, and API keys in these sketches are **placeholders**. Replace them before flashing.
