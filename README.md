# ESP32 / Arduino builds

Personal ESP32 and Arduino builds: a wireless door alarm, Wi‑Fi home control, light-sensing blinds, and a proximity lamp.

Writeup: [portfolio page](https://nmahadevan12.github.io/projects/home-esp-builds/)

| Folder | What it is |
| --- | --- |
| [`door-alarm`](./door-alarm) | Reed-switch door sensor — `sensor-node/` · `espnow-hub/` · `web-logger/` · `discord-hub/` |
| [`wifi-home-control`](./wifi-home-control) | Wi‑Fi page for blinds and lamps — `hub/` · `blinds/` · `lamps/` |
| [`light-sensing-blinds`](./light-sensing-blinds) | Photoresistor blinds with auto / manual modes |
| [`proximity-lamp`](./proximity-lamp) | Ultrasonic proximity toggle lamp |

## Setup notes

Wi‑Fi SSIDs, passwords, phone numbers, and API keys in these sketches are **placeholders**. Replace them before flashing.
